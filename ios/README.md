# Loupe iOS (epic #6, children 5 and 6; epic #7)

SwiftUI, iOS 17+, bundle id `com.loupe-ai.ios`. The Xcode project is generated by XcodeGen from `project.yml` (the `.xcodeproj` is git-ignored).

## Build and run
```bash
# 1. Native Laya pieces, then the engine XCFramework (from repo root)
ios-native/build.sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@21 && ./gradlew :loupe-kit:assembleLoupeKitDebugXCFramework
# 2. Project + tests
cd ios && brew install xcodegen && xcodegen generate
xcodebuild test -project Loupe.xcodeproj -scheme Loupe -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max'
```
DEBUG-only launch arguments: `-LoupeTab now|guard|judgments|sources|me|web` (`web` = Judgments → Web questions), `-LoupeEphemeralKeychain` (in-memory key store), `-LoupeFixtures` (bundled fixture offers, no network), `-LoupeAutoSearch`, `-LoupeModelState ready|missing` (the decision model reads as ready or missing whatever the files; UI tests), `-LoupeSkipOnboarding` (no Get the Loupe Decision Model step, no intro), `-LoupeResultsFixture <n>` / `-LoupeResultsPerf` (the judgment results dashboard on n synthetic items; perf line).

- Sorting (epic #7 child 6, F1 + F2): `Loupe/Sort/` over LoupeKit's shared `SweepCoordinator` + `ModelLane`. Every model call in the app (Results sweeps, sorting, the watchers' model half, flight ranking, the game's pilot) runs on the one serial queue `ModelWork.queue`; priorities are foreground > game > sweep, and a sort stops between items when anything above it claims the lane, then resumes by itself when it is free. A run sweeps every judgment over every enabled source, skipping items already judged under the current criteria hash, then runs the watchers; progress shows done/total, items/s and median latency; Cancel works; any stop is checkpointed (rows are in the ledger) and the next run resumes. Me → "Sort while charging" (**off by default**; turning it on asks for notification permission) schedules a `BGProcessingTask` `com.loupe-ai.ios.sort` (`requiresExternalPower`, no network; `BGTaskSchedulerPermittedIdentifiers` + `UIBackgroundModes: processing` in `project.yml`); its expiration handler stops at the next item. Runs refuse, or stop, at thermal `.serious`/`.critical` and in Low Power Mode. Me → "Run now" runs it in the foreground. A local notification and a Now card show the last run's real counts ("412 sorted, 9 need you"). DEBUG: `-LoupeSortDemo` (with `-LoupeFixtures`; stand-in scorer, throwaway ledger).
  - **Trigger the background task in the simulator:** run the app from Xcode, turn on Me → "Sort while charging", send the app to the background (so the request is submitted), pause in the debugger and enter
    `e -l objc -- (void)[[BGTaskScheduler sharedScheduler] _simulateLaunchForTaskWithIdentifier:@"com.loupe-ai.ios.sort"]`
    then continue. To test expiry, while it runs pause again and enter
    `e -l objc -- (void)[[BGTaskScheduler sharedScheduler] _simulateExpirationForTaskWithIdentifier:@"com.loupe-ai.ios.sort"]`.
    (The simulator refuses real `submit` calls; the handler logic is covered by `LoupeTests/SortTests.swift` with a fake scheduler.)

  - Usage strings (`project.yml`): Photos, Calendars (full access), Contacts — plain language, "Nothing leaves the phone."

## Model delivery and device verification (epic #7 child 9)
- **Manifest** `Loupe/Resources/Laya/models.json`: variants `int8` (default) and `int8-partial` (opt-in), each file's name, size and SHA-256 (the same pins as LoupeKit's `LayaModelStore`; `ModelDeliveryTests` checks they agree), and `source.host` + `source.urlTemplate` (`{host}`, `{variant}`, `{file}`). **Host (2026-09-25): the owner's Supabase Storage public bucket** — `https://zqyeihzjpfnvkrprcwam.supabase.co`, template `{host}/storage/v1/object/public/models/laya/v1/{file}` (Range, ETag and Last-Modified served, so resume data works). v1 is never overwritten: a re-export goes to `laya/v2/` with new pins. With an empty host (or DEBUG `-LoupeNoModelHost`) Me → Decision model says "Model host not configured", Get the Loupe Decision Model says the build cannot download the decision model, Download is not offered, and no request is made. UI tests never tap Download with consent (`-LoupeResetModelConsent` + decline), so the suite makes no model request.
- **Download** (`Loupe/Laya/ModelDownloader.swift`): consent screen first (size, one-time, only the model files go online, SHA-256 check, not backed up, removable); then a background `URLSession` download task per file (continues while suspended, relaunch via `handleEventsForBackgroundURLSession`), mobile data only if the user allows it, progress, Pause/Resume (resume data kept on disk, survives a quit), disk-space precheck (remaining + 200 MB against important-usage capacity), each file hashed (streaming SHA-256) in `Application Support/Loupe/laya-download/` and only on a match renamed atomically into `Application Support/Loupe/laya-multilingual/`, excluded from iCloud backup. ## On your iPhone (owner steps)
Everything below needs the owner's accounts or hardware; the code for each is built.
1. **Apple Developer account** (paid, for App Groups and TestFlight). Find the **Team ID**: developer.apple.com → Account → Membership details.
2. **Team ID locally:** `cp ios/Config/Signing.local.xcconfig.example ios/Config/Signing.local.xcconfig` and set `DEVELOPMENT_TEAM`. The file is git-ignored; `project.yml` reads it through `Config/Signing.xcconfig`.
3. **Identifiers:** in Certificates, Identifiers & Profiles register App IDs `com.loupe-ai.ios`, `com.loupe-ai.ios.share` and `com.loupe-ai.ios.safari` (or let Xcode's automatic signing create them on the first build), and the **App Group `group.com.loupe-ai.ios`**, enabled on all three (the Share Extension inbox, the lists and the Spotted log Loupe for Safari reads; `Loupe/Loupe.entitlements`, `LoupeShare/LoupeShare.entitlements`, `LoupeSafari/LoupeSafari.entitlements`). If `com.loupe-ai.*` is taken, change the bundle ids in `project.yml`, the group in the three entitlements files, `SharedInbox.swift` and `Shared/Protection/ProtectionGroup.swift` together.
4. **Background task:** nothing to register — `BGTaskSchedulerPermittedIdentifiers: [com.loupe-ai.ios.sort]` and `UIBackgroundModes: [processing]` are in `project.yml`; the model download's background `URLSession` needs no entitlement.
5. **Device:** iPhone with Developer Mode on (Settings → Privacy & Security), unlocked, trusted, by cable. Build LoupeKit's device slice (`ios-native/build.sh`, then `./gradlew :loupe-kit:assembleLoupeKitDebugXCFramework`), then `ios/scripts/device-build.sh` (builds Debug, installs with `devicectl`; `--device <UDID>` to pick one; it stops with a clear message when the team, LoupeKit's device slice or a device is missing).
6. **OAuth mail:** the Google iOS client (bundle `com.loupe-ai.ios`) is set as `GOOGLE_IOS_CLIENT_ID` / `GOOGLE_IOS_URL_SCHEME` in `project.yml`; its consent screen is in Testing, so only listed test users can sign in. A Microsoft app registration → `LoupeMicrosoftOAuthClientID` (optional).
7. **Model host: done 2026-09-25** — Supabase Storage, public bucket `models`, files under `laya/v1/` (set in `models.json`; SHA-256s checked against the pins). A re-export: upload under a new path (`laya/v2/`), then change `urlTemplate`, sizes and pins together; never overwrite v1. To skip the download on your own phone and copy the files into the app's container with Xcode (Devices → Loupe → Download/Replace Container, `Library/Application Support/Loupe/laya-multilingual/`).
8. **Run Diagnostics:** Me → Decision model → Download (or side-load), then Me → Diagnostics → 3–5 passes → Run, unplugged, screen on; Share the JSON back. For 10+ minutes of battery data, raise the passes. For TestFlight: `ios/scripts/device-build.sh --diagnostics-archive`, upload from Xcode's Organizer; the screen shows only in TestFlight installs.
9. **Loupe for Safari:** after installing, Guard → Protection → "Turn on Safari protection" (iOS 26.2+ opens Safari's settings at Loupe): turn on **Allow Extension**, then **All Websites → Allow** (left on Ask, Safari asks per site). Older iOS: Settings → Apps → Safari → Extensions → Loupe. Then open any site in Safari; the card shows On. To see a warning without a real phishing site, open Guard → Check a link with `xn--pypal-4ve.com`, or serve any page on the Mac and open it as `http://xn--pypal-4ve.<mac-ip>.nip.io:<port>/`.

# Loupe iOS (epic #6, children 5 and 6; epic #7)

SwiftUI, iOS 17+, bundle id `dev.loupe.app`. The Xcode project is generated by XcodeGen from `project.yml` (the `.xcodeproj` is git-ignored).

## Build and run
```bash
# 1. Native Laya pieces, then the engine XCFramework (from repo root)
ios-native/build.sh
export JAVA_HOME=/opt/homebrew/opt/openjdk@21 && ./gradlew :loupe-kit:assembleLoupeKitDebugXCFramework
# 2. Project + tests
cd ios && brew install xcodegen && xcodegen generate
xcodebuild test -project Loupe.xcodeproj -scheme Loupe -destination 'platform=iOS Simulator,name=iPhone 17 Pro Max'
```
DEBUG-only launch arguments: `-LoupeTab now|web|…`, `-LoupeEphemeralKeychain` (in-memory key store), `-LoupeFixtures` (bundled fixture offers, no network), `-LoupeAutoSearch`.

## Done
- Shell: Now (navy hero, logo, mascot), Judgments, Web, Sources, Me. Non-Web tabs show honest empty states, no fake data. Me reads facts from LoupeKit (built-in judgments, PSL version).
- Web · Flights: explainer, Duffel key (prefix check, verify via `/v1/health` + probe search, Keychain `WhenUnlockedThisDeviceOnly`), settings (helper on/off, Flights on/off, Remove key), search form, typed helper errors, NWPathMonitor offline state, Online badge, test-data banner, copyable hand-off text. Loupe never books or pays.
- Ranking on device: `OfferRanker` protocol, `RuleBasedRanker` (stops, price cap, departure window, bags, refundable). The only network target is loupe-web-helper.

- Laya ranks on device (`Loupe/Web/LayaRanker.swift` over LoupeKit `FlightJudge`), off the main thread, cancellable; the rule ranking stays alongside with a toggle and a #1-disagreement line; offers the engine would not act on are marked unsure.
- Me → Laya model: the consented one-time download (~418 MB, SHA-256 checked; see "Model delivery" below). Me → Licences: iOS notices and the font OFLs.
- Dev model: install the app on the simulator, then `ios-native/sideload-models.sh dev.loupe.app booted`. `LoupeTests/LayaOnDeviceTests` runs the real model when present and skips otherwise.

- Game (epic #7 G): `Loupe/Game/` — SpriteKit river over the KMP `:game` rules from LoupeKit. Now → Play card or Me → Game. You fly (drag steer, hold fire, tap pause, auto-fire) or Watch Laya (raw probability bars, decisions/s, scoreboard vs the baseline on the same seed; baseline + note without the model). Pauses on background; reduced motion; haptics toggle. DEBUG args: `-LoupeGame human|watch`, `-LoupeSeed n`, `-LoupeGameLog` (fps/decisions per second to stdout), `-LoupeSkipOnboarding`.

- Ledger (epic #7 child 1): every Laya-ranked offer is an A5 row (`web:duffel:<offer>`, model/unusable, propensity, truncation) appended and fsynced to Application Support/Loupe/ledger.jsonl in the desktop format (`Loupe/Ledger/LedgerService.swift` over LoupeKit `PhoneLedger`). Me shows the count and "Export my data": the desktop's four F4 files, zipped, via the share sheet. Tests and `-LoupeFixtures` use a throwaway ledger.

- Sources (epic #7 child 2): the synthetic sample (the desktop's sample resources, bundled as `sample/`) read by LoupeKit's common scanner (`:sources-common`) with PDFKit and ImageIO as the platform readers (`Loupe/Sources/AppleExtractors.swift`), off the main thread with progress, cached in Application Support/Loupe/sources (`SourcesService`, over LoupeKit `SourceLibrary`). The Sources tab shows "Sample data — not from your phone" (on by default, switchable off), its item count and last scan; `SourcesService.items()` is what Judgments and Now read next.

- Judgments (epic #7 child 3): `Loupe/Judgments/` over LoupeKit's `JudgmentBook` / `JudgmentSweep` / `JudgmentResults`. Library: the 55 templates by their 10 categories, search, detail (answers, three-part criteria, posture, baseline, examples, parameters), "Use this". Write your own: live lint, yes/no (options that say what they mean; bare yes/no refused), score (named bands), pick one; criteria-in-prompt off by default with the calibration-restart warning. My judgments: counts per judgment. Results: runs over the sample with Laya on a background queue (progress, cancel), decisions appended to the ledger; confidence, source, "answered by rule", cut notes, unsure markers. Without the model it says "Model not installed" and shows no scores. DEBUG: `-LoupeJudgmentDemo tax-receipt` (adds it, opens its results, runs), `-LoupeLibrary`.

- Unsure queue + measurement (epic #7 child 4): `Loupe/Judgments/UnsureQueueView.swift` and `MeasureView.swift` over LoupeKit's `JudgmentMeasure`. Now and My judgments show "Needs you: N" (the queue across all judgments: most torn first plus a random fifth of confident answers); one tap per option, Skip, Undo; answers go to the corrections log keyed by item + criteria hash. Results → Measure: counts, agreement (from 10 corrections), ECE/Brier/reliability bins (from 30, otherwise how many more), the baseline vs the model on your corrected items (says so when the baseline wins, with "Use the baseline"), and the threshold slider with its counterfactual over logged rows; Use writes the threshold. Me: "Agrees with you X% over N corrections" from 10, otherwise how many more. DEBUG: `-LoupeQueueDemo` (with `-LoupeFixtures`; stand-in scorer, throwaway ledger), `-LoupeOpen queue` (Now's queue) or `measure` (with `-LoupeJudgmentDemo`).

- Watchers on Now (epic #7 child 5): `Loupe/Now/` over LoupeKit's shared `WatcherRun` + `WatcherFindings`. Runs the five watchers whenever the scanned items change (expiry's model half when Laya is installed); the hero shows the top finding, then every finding with its watcher, evidence lines, why, Confirm / Dismiss / Not relevant (corrections log, Undo) and Open item; the subscriptions census with a monthly total. Loading and empty states say what is true; sample findings carry a Sample pill; the mascot shows `found` for findings not seen before.

- Sorting (epic #7 child 6, F1 + F2): `Loupe/Sort/` over LoupeKit's shared `SweepCoordinator` + `ModelLane`. Every model call in the app (Results sweeps, sorting, the watchers' model half, flight ranking, the game's pilot) runs on the one serial queue `ModelWork.queue`; priorities are foreground > game > sweep, and a sort stops between items when anything above it claims the lane, then resumes by itself when it is free. A run sweeps every judgment over every enabled source, skipping items already judged under the current criteria hash, then runs the watchers; progress shows done/total, items/s and median latency; Cancel works; any stop is checkpointed (rows are in the ledger) and the next run resumes. Me → "Sort while charging" (**off by default**; turning it on asks for notification permission) schedules a `BGProcessingTask` `dev.loupe.app.sort` (`requiresExternalPower`, no network; `BGTaskSchedulerPermittedIdentifiers` + `UIBackgroundModes: processing` in `project.yml`); its expiration handler stops at the next item. Runs refuse, or stop, at thermal `.serious`/`.critical` and in Low Power Mode. Me → "Run now" runs it in the foreground. A local notification and a Now card show the last run's real counts ("412 sorted, 9 need you"). DEBUG: `-LoupeSortDemo` (with `-LoupeFixtures`; stand-in scorer, throwaway ledger).
  - **Trigger the background task in the simulator:** run the app from Xcode, turn on Me → "Sort while charging", send the app to the background (so the request is submitted), pause in the debugger and enter
    `e -l objc -- (void)[[BGTaskScheduler sharedScheduler] _simulateLaunchForTaskWithIdentifier:@"dev.loupe.app.sort"]`
    then continue. To test expiry, while it runs pause again and enter
    `e -l objc -- (void)[[BGTaskScheduler sharedScheduler] _simulateExpirationForTaskWithIdentifier:@"dev.loupe.app.sort"]`.
    (The simulator refuses real `submit` calls; the handler logic is covered by `LoupeTests/SortTests.swift` with a fake scheduler.)

- Phone sources (epic #7 child 7): `Loupe/Sources/Phone/` and `Loupe/Sources/Mail/`, each a `SourceItem` producer stored through LoupeKit's `SourceLibrary` beside the sample, so Judgments, Now's watchers and the sort read them. **Every source is off by default; its iOS permission is asked only when the user turns it on** in Sources, and off removes its items (Mail: no request is made). Rows show permission state, item count, skipped/unavailable, last scan, and errors with recovery text (Open Settings, Choose more photos, use an app password).
  - Photos: PhotoKit (limited library aware), ImageIO metadata from the bytes, Vision `VNRecognizeTextRequest` (`.accurate`, language correction, on device); screenshots flagged; incremental (unread photos newest first, 300 per scan; edits via `PHPersistentChangeToken`; deletions dropped); iCloud-only originals are not downloaded.
  - Files: `UIDocumentPickerViewController` (files and folders, opened in place), security-scoped bookmarks in `Application Support/Loupe/sources/bookmarks.json`, re-scanned on every open. **Send to Loupe**: the `LoupeShare` Share Extension copies shared files, links and text into the App Group `group.dev.loupe.app` inbox (`ios/Shared/SharedInbox.swift`), read as the `shared` source.
  - Calendar: EventKit full read access (never writes); one item per occurrence, a year either side. Contacts: names, emails, phones; the address book feeds the impersonation watcher (shared `WatcherRun.addressBook`), and contacts are never judged.
  - Mail (**Online**): read-only IMAP over TLS on 993 (`Loupe/Sources/Mail/IMAP.swift`, Network.framework, no dependencies): EXAMINE + `BODY.PEEK` so nothing is marked read, a command allowlist, UIDVALIDITY/UID incremental (newest 200 first). App password in the Keychain (`WhenUnlockedThisDeviceOnly`); messages kept as `.eml` under `Application Support/Loupe/mail/` and parsed by the shared MIME parser; every item carries "Online · host · fetched …". Presets: iCloud, Fastmail, Gmail (app password), other. Remove mailbox deletes the password, the messages and the items.
  - OAuth (Gmail/Outlook): `Loupe/Sources/Mail/OAuth.swift` — ASWebAuthenticationSession, PKCE S256, state check, token refresh, SASL XOAUTH2 — **gated**: `LoupeGoogleOAuthClientID` / `LoupeMicrosoftOAuthClientID` in `project.yml` are empty, and the Mail screen says "Needs a Google/Microsoft OAuth client ID".
  - Usage strings (`project.yml`): Photos, Calendars (full access), Contacts — plain language, "Nothing leaves the phone."
  - Tests: `LoupeTests/PhoneSourcesTests.swift` (fakes for PhotoKit/EventKit/Contacts, bookmarks, recorded IMAP transcripts in `LoupeTests/Fixtures/imap-*.txt`, OAuth, Keychain; no network), `LoupeUITests/SourcesUITests.swift`.

- Privacy check (epic #7 child 10): `Loupe/Privacy/` over LoupeKit's shared `dev.loupe.kit.privacy` (Loupe Station's `pii_rules`, `secret_rules`, `dupes` and name hints, ported verbatim from the owner's repo at `ea7697a`). Now → "Privacy check: N findings" card, or Sources → Privacy check. Runs over every enabled source on the model queue at sweep priority (no model). Findings grouped: keys/tokens/private keys, IDs and passports, card numbers, IBANs, phone numbers and emails (contact lists), payroll, duplicate files; masked previews only. Actions: Open, Mark safe (corrections log, Undo); for picked Files / Send to Loupe items Delete (confirm; Undo until you leave the screen) and Move to a folder (Undo); Photos delete through PhotoKit's own prompt; sample, mail and calendar are suggest-only. Tests: `LoupeTests/PrivacyTests.swift`, `LoupeUITests/PrivacyUITests.swift`.
- Mail triage and site checks (epic #7 children 11 and 12): `Loupe/Mail/` (`MailTriageService`, `MailTriageView`) over LoupeKit's shared `dev.loupe.kit.mail` (Loupe Station's `mail/phishing.py` evidence, `mail/classify.py` labels and the `wf-email-triage` keyword rules) and `dev.loupe.kit.site` (Station's `browser/brands.py` brand list and `browser/signals.py`/`scoring.py` weights, beside the engine's `SiteFraud`), ported from the owner's repo at `ea7697a`. Now → "Mail triage: N possible phishing · M need a reply" card, or Sources → Mail. Every email of the enabled sources (the sample inbox; IMAP mail when on; `.eml` files are re-read for Reply-To, Authentication-Results and link text): sections Phishing suspected, Spam, Needs reply, Urgent, By category (Station's categories: supplier invoice, bank payment, government tax, newsletter/marketing, …), with the concrete signals (look-alike sender domain vs brand, the display name claiming a brand, reply-to elsewhere, DMARC/SPF, a link going somewhere else, urgent wording) and each link's site check. Actions: Open, Mark safe / Confirm phishing (corrections log `mail-phishing`, Undo). Web links found in other items (e.g. links sent to Loupe) get the same site checks. Mechanical, on the model queue at sweep priority. Tests: `LoupeTests/MailTriageTests.swift`, `LoupeUITests/MailTriageUITests.swift`.

## Model delivery and device verification (epic #7 child 9)
- **Manifest** `Loupe/Resources/Laya/models.json`: variants `int8` (default) and `int8-partial` (opt-in), each file's name, size and SHA-256 (the same pins as LoupeKit's `LayaModelStore`; `ModelDeliveryTests` checks they agree), and `source.host` + `source.urlTemplate` (`{host}`, `{variant}`, `{file}`). **The host ships empty**: Me → Laya model says "Model host not configured", Download is not offered, and no request is made.
- **Download** (`Loupe/Laya/ModelDownloader.swift`): consent screen first (size, one-time, only the model files go online, SHA-256 check, not backed up, removable); then a background `URLSession` download task per file (continues while suspended, relaunch via `handleEventsForBackgroundURLSession`), mobile data only if the user allows it, progress, Pause/Resume (resume data kept on disk, survives a quit), disk-space precheck (remaining + 200 MB against important-usage capacity), each file hashed (streaming SHA-256) in `Application Support/Loupe/laya-download/` and only on a match renamed atomically into `Application Support/Loupe/laya-multilingual/`, excluded from iCloud backup. Remove deletes both folders' model files and withdraws consent. This is the only network code on the model path.
- Adapted from Loupe Station's `ModelStore.swift` (the owner's repo `~/laya-studio/macos/Sources/LoupeStation/ModelStore.swift`, with its pinned `models.json`): the bundled manifest, streaming hash check, space margin and "a partial file never sits where a finished one is loaded". Not taken: the macOS hub-cache layout, git-blob SHA-1 checks, `NWPathMonitor` preflight and Range-append data tasks (iOS background sessions need download tasks and resume data).
- **Diagnostics** (Me → Diagnostics; DEBUG builds, or a `LOUPE_DIAGNOSTICS` Release build under TestFlight only): runs the 34 golden + 8 criteria parity questions through the real on-device Laya (`LayaOnPhone.scoreCase`, on the model queue) for N timed passes after one warm-up, and reports per-question agreement with the pinned JVM INT8 answers (and max |Δp|), p50/p95 latency by token length, peak `phys_footprint` (`task_vm_info`), thermal state over the run, a battery-drain estimate, device model and iOS version; Share exports the report JSON. The expectations are `Loupe/Resources/Diagnostics/laya-diagnostics.json`, generated by `ios/scripts/make-diagnostics-fixtures.py` from backend-onnx's fixtures and excluded from Release.
- Tests: `LoupeTests/ModelDeliveryTests.swift` (manifest, SHA good/bad/partial, disk space, consent gating, pause/resume/background-finish with a fake transport), `LoupeTests/DiagnosticsTests.swift` (percentiles, buckets, battery, report, fixture = JVM fixtures), `LoupeUITests/ModelDeliveryUITests.swift`.

## On your iPhone (owner steps)
Everything below needs the owner's accounts or hardware; the code for each is built.
1. **Apple Developer account** (paid, for App Groups and TestFlight). Find the **Team ID**: developer.apple.com → Account → Membership details.
2. **Team ID locally:** `cp ios/Config/Signing.local.xcconfig.example ios/Config/Signing.local.xcconfig` and set `DEVELOPMENT_TEAM`. The file is git-ignored; `project.yml` reads it through `Config/Signing.xcconfig`.
3. **Identifiers:** in Certificates, Identifiers & Profiles register App IDs `dev.loupe.app` and `dev.loupe.app.share` (or let Xcode's automatic signing create them on the first build), and the **App Group `group.dev.loupe.app`**, enabled on both (the Share Extension inbox; `Loupe/Loupe.entitlements`, `LoupeShare/LoupeShare.entitlements`). If `dev.loupe.*` is taken, change the bundle ids in `project.yml`, the group in both entitlements files and `SharedInbox.swift` together.
4. **Background task:** nothing to register — `BGTaskSchedulerPermittedIdentifiers: [dev.loupe.app.sort]` and `UIBackgroundModes: [processing]` are in `project.yml`; the model download's background `URLSession` needs no entitlement.
5. **Device:** iPhone with Developer Mode on (Settings → Privacy & Security), unlocked, trusted, by cable. Build LoupeKit's device slice (`ios-native/build.sh`, then `./gradlew :loupe-kit:assembleLoupeKitDebugXCFramework`), then `ios/scripts/device-build.sh` (builds Debug, installs with `devicectl`; `--device <UDID>` to pick one; it stops with a clear message when the team, LoupeKit's device slice or a device is missing).
6. **OAuth mail (optional):** a Google OAuth iOS client ID and a Microsoft app registration → `LoupeGoogleOAuthClientID` / `LoupeMicrosoftOAuthClientID` in `project.yml`.
7. **Model host:** upload `tokenizer.json`, `laya-multilingual-choice.int8.onnx` (and optionally `…int8-partial.onnx`) — the exact files whose SHA-256s are in `models.json` — to an HTTPS host that serves plain GETs (e.g. a pinned Hugging Face revision: host `https://huggingface.co`, template `{host}/<you>/<repo>/resolve/<commit>/{file}`), then set `source.host` / `source.urlTemplate`. Or skip the host for your own phone and copy the files into the app's container with Xcode (Devices → Loupe → Download/Replace Container, `Library/Application Support/Loupe/laya-multilingual/`).
8. **Run Diagnostics:** Me → Laya model → Download (or side-load), then Me → Diagnostics → 3–5 passes → Run, unplugged, screen on; Share the JSON back. For 10+ minutes of battery data, raise the passes. For TestFlight: `ios/scripts/device-build.sh --diagnostics-archive`, upload from Xcode's Organizer; the screen shows only in TestFlight installs.

# Laya 0.3.20 upgrade: before vs after (issue #8, 2026-09-24)

**Synthetic data. None of these numbers measures accuracy.** The sample is 45 invented text items. Template examples are 2–3 per template, written with the templates. "Agrees with baseline" counts matches with the keyword rule, which is not ground truth. Hand labels exist only for three yes/no judgments, and those labels were written by the person measuring.

- **Before:** laya pin `c7527708` (0.3.6), score levels sent in written order.
- **After:** laya `23a17522` (0.3.20) plus Station's `REVERSE_SCORE_ON` (score levels sent highest first, mapped back).
- **Model:** INT8 ONNX on the desktop JVM. The graph and every token sequence are identical under both pins (golden 34/34 and criteria 8/8 input ids unchanged; torch probabilities within 1e-8), so the only live difference is the score reversal. It touches the one score template, `urgency`.
- **Generated by** `loupe-desktop/src/test/kotlin/dev/loupe/desktop/LayaUpgradeMeasurementTest.kt` (gated on `models/`).

Examples: 2/3 before, 2/3 after; the baseline gets 3/3. Station measured a gain on real labels (score clear-cut 83 → 115 of 191). Here nothing can say whether the changed answers are better.
